# bankval
Это проект для валидации операций клиента, написанный на языке программирования python.<br>
Проект использует poetry (популярный инструмент для управления зависимостями)

# Запуск проекта
Для проверки проекта по flake8, mypy, isort, запустите файл shell/check.sh
```sh
chmod +x ./shell/check.sh
./shell/check.sh
```
Для запуска проекта запустите файл shell/run.sh
```sh
chmod +x ./shell/run.sh
./shell/run.sh
```
